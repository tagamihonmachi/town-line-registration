# 町会LINE 利用者登録フォーム

LINE公式アカウントの友だちが、LINEの中から年代・班・世帯属性を登録するためのフォームです。
回答はGoogleスプレッドシートに保存され、同じ人が登録し直すと既存の行が更新されます。

## しくみ

```
LINEアプリ(LIFF)                Google Apps Script              LINE Platform
  index.html / app.js
        │  ① IDトークン + 回答
        ├──────────────────────────▶ Code.gs
        │                              │ ② IDトークンを検証
        │                              ├──────────────────────────▶ /oauth2/v2.1/verify
        │                              │◀──────────────────────────  sub(LINEユーザーID)
        │                              │ ③ スプレッドシートに追加 / 更新
        │◀──────────────────────────  結果
```

- フォームはLINEユーザーIDや表示名を送りません。送るのはIDトークンと回答だけです。
- LINEユーザーIDは、サーバーがLINEに問い合わせて検証した結果(`sub`)だけを使います。
- スプレッドシートに保存するのはLINEユーザーIDと回答、日時のみです(名前やアイコンは保存しません)。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | フォーム画面 |
| `config.js` | 画面側の設定(LIFF ID、GASのURL、班の選択肢) |
| `config.example.js` | `config.js` の見本 |
| `gas/Code.gs` | Google Apps Script に貼り付けるサーバー側コード |
| `gas/Admin.gs` / `gas/Admin.html` | 配信管理画面(Apps Script に追加するファイル) |

## 設定値の一覧

| 値 | 置き場所 | 公開してよいか |
|---|---|---|
| LIFF ID | `config.js` の `LIFF_ID` | よい |
| GASウェブアプリのURL | `config.js` の `GAS_URL` | よい |
| 班の選択肢 | `config.js` の `HAN_OPTIONS` | よい |
| LINE Login の Channel ID | GASのスクリプトプロパティ `LINE_LOGIN_CHANNEL_ID` | よい(ただし画面側では使いません) |
| スプレッドシートのID | GASのスクリプトプロパティ `SPREADSHEET_ID`(省略可) | 置かない |
| Channel Secret | **どこにも置きません**(この方式では不要) | 不可 |

`config.js` はブラウザから誰でも読めるファイルです。秘密情報は書かないでください。

## セットアップ手順

### 1. スプレッドシートとApps Script

1. 保存先のGoogleスプレッドシートを新しく作ります。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードを消し、`gas/Code.gs` の内容をすべて貼り付けて保存します。
4. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に次を追加します。
   - `LINE_LOGIN_CHANNEL_ID` : LINE LoginチャネルのチャネルID(数字)
5. 同じ画面でタイムゾーンが「(GMT+09:00) 東京」になっていることを確認します。
6. エディタに戻り、関数 `setup` を選んで「実行」します。権限の確認画面が出たら承認します。
   スプレッドシートに「登録者」シートと見出し行ができれば成功です。

### 2. ウェブアプリとして公開

1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
2. 次のように設定してデプロイします。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
3. 表示された「ウェブアプリのURL」(末尾が `/exec`)を控えます。
4. ブラウザでそのURLを開き、`{"ok":true,"service":"registration"}` と表示されれば動いています。

「全員」にするのは、LINEアプリから送信を受け取るためです。URLを知っていても、LINEが発行した正しいIDトークンがなければ登録はできません。

`Code.gs` を後から直したときは、「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」でデプロイし直してください(URLは変わりません)。

### 3. フォームの公開

1. `config.js` の `LIFF_ID` と `GAS_URL` を本物の値に書き換えます。
2. `index.html` `style.css` `app.js` `config.js` の4つを、HTTPSで公開できる場所に置きます
   (GitHub Pages、Cloudflare Pages、Netlify など)。`gas/` フォルダは公開不要です。
3. LINE Developers コンソール → LINE Loginチャネル → LIFF で、対象のLIFFアプリの
   「エンドポイントURL」を、公開した `index.html` のURLにします。
4. Scope で `openid` にチェックが入っていることを確認します。

### 4. 動作確認

1. スマホのLINEで `https://liff.line.me/<LIFF ID>` を開きます。
2. 項目を選んで「登録する」を押し、「登録ありがとうございました」と表示されることを確認します。
3. スプレッドシートに1行追加されていることを確認します。
4. もう一度開いて内容を変えて登録し、行が増えずに同じ行が更新されることを確認します。
   2回目以降に開くと、前回の登録内容が選ばれた状態で表示されます(本人の内容だけを、IDトークンで本人確認してから読み込みます)。

リッチメニューから開けるようにするには、リンク先に `https://liff.line.me/<LIFF ID>` を設定します。

## パソコンで画面だけ確認する

`config.js` がダミー値のままなら、`index.html` をブラウザで開くと「プレビュー表示」になります。
LINEへのログインも送信も行わず、見た目と入力チェックだけを確認できます。

## よくある変更

### 班の選択肢を変える

`config.js` の `HAN_OPTIONS` を書き換えて、公開先のファイルを差し替えるだけです。Apps Script 側の変更は不要です。

```js
HAN_OPTIONS: ['1班', '2班', '3班', '東班', '西班'],
```

- 1つの名前は20文字以内にしてください。
- すでに登録済みの人の班は、自動では書き換わりません。

### 年代・世帯属性の選択肢を変える、「所属」を戻す

`index.html` の選択肢と、`gas/Code.gs` 冒頭の `AGE_OPTIONS` / `HOUSEHOLD_OPTIONS` の両方を直し、
Apps Script を新バージョンでデプロイし直します。列が増減する場合は、スプレッドシートの見出し行も合わせて直してください。

「所属」(子ども会・町会役員)の項目は現在外してあります。戻すときは、`index.html` に項目を追加し、`app.js` の `readAnswers` に
`groups: data.getAll('groups')` を加え、`gas/Code.gs` の `GROUP_OPTIONS` に選択肢を指定します。

## スプレッドシートの列

| LINEユーザーID | 年代 | 班 | 未就学児 | 小学生 | 中学生 | 65歳以上 | 登録日時 | 更新日時 |
|---|---|---|---|---|---|---|---|---|

あてはまる項目には「○」が入ります。A列(LINEユーザーID)と見出し行は、並べ替えや書き換えをしないでください
(同じ人の再登録を見分けるために使っています)。

## 配信管理画面

登録者の年代・班・世帯属性で相手を絞り込み、LINEのメッセージを送るための管理者用の画面です。
コードを触らずに、対象人数の確認、自分へのテスト送信、本番送信ができます。

### 誰が使えるか

- 管理画面用のデプロイは、アクセスを「自分のみ」にします。Googleにログインしていないと開けません。
- さらにコード側で、スクリプトプロパティ `ADMIN_EMAILS` に登録したGoogleアカウントだけを通します。
  登録フォーム用の公開URLに `?page=admin` を付けても、管理画面は表示されず、送信もできません。
- チャネルアクセストークンは画面には一切出ません。

### セットアップ

1. Apps Script のエディタで、`Code.gs` の中身を `gas/Code.gs` の全文に置き換えます。
2. 「ファイル」の「＋」→「スクリプト」で `Admin` という名前のファイルを作り、`gas/Admin.gs` の全文を貼り付けます。
3. 「＋」→「HTML」で `Admin` という名前のファイルを作り、`gas/Admin.html` の全文を貼り付けます
   (ファイル名は `Admin.html` になります)。
4. 「プロジェクトの設定」→「スクリプト プロパティ」に次を追加します。

   | プロパティ | 値 |
   |---|---|
   | `ADMIN_EMAILS` | 管理画面を使うGoogleアカウントのメールアドレス(このスクリプトをデプロイするアカウント) |
   | `ADMIN_LINE_USER_ID` | テスト送信を受け取る管理者のLINEユーザーID(「登録者」シートのA列にある、自分の行の値) |
   | `LINE_IMAGE_FOLDER_ID` | 画像を付けて配信する場合だけ必要。設定方法は下の「画像付きの配信」を参照 |

5. 「デプロイ」→「**新しいデプロイ**」→ 種類「ウェブアプリ」を選び、次のように設定します。
   - 説明: 配信管理画面
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**
6. 表示されたURLの末尾に `?page=admin` を付けたものが、管理画面のURLです。ブックマークしておきます。

   ```
   https://script.google.com/macros/s/(管理画面用のID)/exec?page=admin
   ```

登録フォーム用のデプロイ(アクセス「全員」)は、そのまま残します。URLも設定も変えません。

### 使い方

1. 配信対象を選びます。何も選ばなければ登録者全員です。
   - 同じ項目で複数選ぶと「どれかに当てはまる人」(例: 30代または40代)
   - 別の項目も選ぶと「すべてに当てはまる人」(例: 30代または40代で、3班で、小学生がいる世帯)
2. 「対象人数を確認」を押します。この操作では送信されません。
3. 本文を入力するか、画像を選びます(両方でもかまいません)。「自分にテスト送信」で自分のLINEに届く内容を確認します。
4. 「本番送信」を押し、確認画面で人数・条件・画像・本文を見てから「送信する」を押します。

配信対象の条件を変えると、もう一度「対象人数を確認」が必要になります。本文や画像の変更なら再確認は不要です。本番送信のあとは、毎回確認からやり直します。

### 配信履歴

テスト送信・本番送信のたびに、スプレッドシートの「配信履歴」シートに1行記録されます(シートは初回に自動で作られます)。
失敗したときも記録されます。

| 配信日時 | 配信種別 | 指定条件 | 対象人数 | メッセージ本文 | 送信結果 | Messaging APIレスポンス | 実行者 | 画像数 | 画像ファイル名 | Google DriveファイルID |
|---|---|---|---|---|---|---|---|---|---|---|

画像が複数あるときは、「画像ファイル名」と「Google DriveファイルID」に、送信した順で1行ずつ(1つのセルの中に改行区切りで)記録されます。

画像の3列は、画像配信の機能を入れる前に作られた履歴シートにも、次の送信時に自動で追加されます。
以前「画像」だった見出しは「画像数」に変わります。過去の行の「あり」(1枚)・「なし」は、そのまま残ります。

### 画像付きの配信

本文に加えて、画像(JPEGまたはPNG)を4枚まで付けられます。画像だけ、本文だけでも送れます。
画面に並んでいる順に、画像1、画像2…、最後に本文の順で届きます(LINEの1回の送信は5件までなので、画像4枚と本文1件が上限です)。

- 「画像を選択」で、一度に複数の画像を選べます。あとから「画像を追加」で足すこともできます。
- 画像ごとに「選び直す」(同じ位置で入れ替え)と「削除」(後ろの画像が前に詰まる)ができます。
- 5枚目を追加しようとすると「画像は最大4枚までです」と表示され、追加されません。

#### しくみ

1. 画面で画像を選ぶと、ブラウザの中で長辺2048px以下のJPEGに変換されます(撮影場所などの付加情報もここで除かれます)。
2. 変換した画像が、Googleドライブの専用フォルダに保存されます。
3. LINEのサーバーが画像を取りに来られるよう、そのファイルは「リンクを知っている全員が閲覧可」になります。
4. 保存直後と送信の直前に、配信用のURLが本当に画像として取得できるかを確認します。複数ある場合は全部を確認し、1枚でも確認できなければ、LINEへは送信しません。

配信用のURLは `https://lh3.googleusercontent.com/d/(ファイルID)` の形式です。通常の共有URL(`drive.google.com/file/d/.../view`)はLINEでは表示できません。

#### 画像を使うための設定

1. Googleドライブに「LINE配信用画像」などの専用フォルダを作ります。
2. フォルダを開いたときのURL `https://drive.google.com/drive/folders/(ここ)` の末尾がフォルダIDです。
3. スクリプトプロパティに `LINE_IMAGE_FOLDER_ID` を追加し、フォルダIDを入れます。
4. Apps Script のエディタで関数 `checkImageFolder` を選んで「実行」し、ドライブの権限を承認します。
   実行ログに「画像の保存先: (フォルダ名)」と出れば成功です。
5. 管理画面用のデプロイを新バージョンに更新します。

手順4を行わないと、管理画面で画像を選んだときに権限のエラーになります。

#### テストの順番

本番送信はせず、「自分にテスト送信」で確認します。

1. 画像1枚+本文を選び、プレビューに画像1、本文の順で表示されることを確認する
2. 画像を1枚追加し、画像2枚+本文になることを確認する
3. さらに2枚追加し、画像4枚+本文になることを確認する
4. 本文を消し、画像4枚だけでもテスト送信ボタンが押せることを確認する
5. 「画像を追加」を押し、「画像は最大4枚までです」と表示されることを確認する
6. 途中の画像を1枚削除し、後ろの画像の番号が前に詰まることを確認する
7. ドライブのフォルダに、選んだ画像がすべて保存されていることを確認する
8. 「自分にテスト送信」を押し、自分のLINEに画面と同じ順番で届くことを確認する
9. 「配信履歴」シートに、画像数・ファイル名・ファイルIDが記録されていることを確認する

#### 知っておくこと

- **保存した画像は消さないでください。** フォルダから削除したり共有を止めたりすると、すでに届いているメッセージの画像が表示されなくなることがあります。
- **画像は、URLを知っている人なら誰でも見られます。** URLは推測できない文字列ですが、住所や顔写真など、広く見られて困るものは載せないでください。
- **このURLの形式は、Googleが公式に保証している配信方法ではありません。** 将来使えなくなった場合は、画像の保存時か送信時に「LINEから取得できる状態にできませんでした」と表示され、送信は行われません。
  そのときは `gas/Admin.gs` の `imageUrls_` を別の配信方法に差し替えます。
- 画像を選び直したり削除したりしても、ドライブのファイルは自動では消えません(テスト送信済みの画像が消えないようにするためです)。

### 班の選択肢を変えたとき

フォーム側の `config.js` を変えたら、`gas/Admin.gs` の `ADMIN_HAN_OPTIONS` も同じ内容にして、管理画面用のデプロイを新バージョンに更新します。
変え忘れても、登録者シートに実際に入っている班名は選択肢に自動で追加されます。

### コードを直したとき

デプロイは2つあり、それぞれ別に更新します。「デプロイを管理」→ 対象のデプロイの鉛筆アイコン → バージョン「新バージョン」。

### 管理画面で困ったとき

| 画面の表示 | 主な原因 |
|---|---|
| この画面を利用する権限がありません | `ADMIN_EMAILS` に、表示されているアカウントが入っていない |
| ログイン中のGoogleアカウントを確認できませんでした | デプロイしたアカウントとは別のアカウントで開いている、または公開用のURLで開いている |
| Googleのエラー画面になる | ブラウザで複数のGoogleアカウントにログインしている。シークレットウィンドウで町会のアカウントだけにログインして開く |
| テスト送信ボタンが押せない | `ADMIN_LINE_USER_ID` が未設定、または形式が違う(`U` で始まる33文字) |
| 画像を選ぶと権限のエラーになる | `checkImageFolder` を実行してドライブの権限を承認していない |
| 画像の保存先フォルダを開けません | `LINE_IMAGE_FOLDER_ID` の値が違う、またはデプロイしたアカウントがそのフォルダを開けない |
| LINEから取得できる状態にできませんでした | ドライブの共有設定が制限されている、またはGoogle側の仕様が変わった。本文だけなら送信できる |
| 対象人数が確認時から変わっています | 確認から送信までの間に登録者が増減した。もう一度「対象人数を確認」を押す |

## 困ったとき

| 画面の表示 | 主な原因 |
|---|---|
| 画面を開けませんでした | `LIFF_ID` の間違い、またはLIFFのエンドポイントURLが公開先と一致していない |
| 本人確認ができませんでした | スクリプトプロパティ `LINE_LOGIN_CHANNEL_ID` が、LIFFアプリのあるチャネルのIDと違う |
| 通信に失敗しました | `GAS_URL` の間違い、ウェブアプリのアクセス設定が「全員」になっていない、電波状況 |
| サーバーでエラーが発生しました | Apps Script の「実行数」でエラー内容を確認(`setup` 未実行、シートの削除など) |
